FORMA — первый сайт вашей студии
================================

Это готовая локальная версия для Visual Studio Code.
FORMA — рабочее название. Его можно заменить на своё.

КАК ОТКРЫТЬ САЙТ В WINDOWS

1. Распакуйте ZIP-архив в отдельную папку forma-studio.
   Все файлы должны находиться рядом, а не внутри разных папок.
2. В Visual Studio Code выберите File → Open Folder.
3. Откройте распакованную папку.
4. В обычном Проводнике Windows дважды нажмите index.html.
   Он откроется в браузере. Не запускайте HTML через Run или F5 в VS Code.
5. Измените файл в редакторе, сохраните Ctrl+S и обновите браузер Ctrl+R.

Если Windows скрывает расширения: index.html может отображаться просто
как index со значком браузера. Это нужный файл.

Установка Node.js, Python, расширений и платных сервисов для этой версии
не требуется. Сайт работает без интернета; внешние ссылки на Telegram,
если их настроить, потребуют интернет.

ФАЙЛЫ ПРОЕКТА

index.html — тексты, разделы, карточки, форма и встроенные SVG-иллюстрации.
style.css — цвета, шрифты, расположение и адаптация к размеру экрана.
script.js — калькулятор, меню, фильтры, окна проектов и подготовка заявки.
START-HERE.txt — эта инструкция.

ЧТО УЖЕ СДЕЛАНО

• Сайт на русском языке с шестью разделами и навигацией.
• Адаптивные стили для компьютеров, планшетов и телефонов.
• Мобильное меню: закрытие по ссылке, клику снаружи и клавише Escape.
• Три демоконцепции, фильтры и подробности в диалоговом окне.
• Выбор услуги и расчёт предварительной стоимости.
• Дополнительные страницы и дополнительные работы в калькуляторе.
• Вопросы и ответы с раскрытием.
• Подготовка заявки, копирование и скачивание в TXT.
• Никаких внешних шрифтов, картинок, библиотек или рекламных счётчиков.
• Поддержка настройки «Уменьшение движения» и клавиатурной навигации.

КАК РЕДАКТИРОВАТЬ

1. Название: в VS Code нажмите Ctrl+Shift+H, найдите FORMA и замените
   на своё название в проекте. Адрес сайта и права на название не проверялись.
2. Основные цвета: начало style.css, блок :root.
3. Тексты: index.html. Ctrl+F поможет найти нужную фразу.
4. Цены: начало script.js, объект STUDIO.
   - landing — лендинг;
   - company — сайт компании;
   - catalog — каталог;
   - extraPage — дополнительная страница;
   - extras — дополнительные работы.
   Стоимости в карточках и калькуляторе обновляются из настроек при запуске.
   Если меняете базовую цену, обновите также её начальное значение в
   index.html для посетителей с выключенным JavaScript.
5. Названия и описание демоконцепций: index.html и объект PROJECTS
   в script.js. Длинные описания диалоговых окон находятся в PROJECTS.

КОНТАКТЫ И ФОРМА

Сейчас форма работает В ДЕМОРЕЖИМЕ: подготавливает текст заявки,
но НИКОМУ его не отправляет. Это прямо указано на сайте.
Имена, контакты и сообщения не сохраняются на сервере или в localStorage.
После обновления страницы заполненный текст будет потерян.

Чтобы включить ссылку на ваш настоящий Telegram:

1. Откройте script.js.
2. В самом начале найдите строку:

   telegram: "",

3. Вставьте между кавычками ваше настоящее имя пользователя без @.
   Используйте имя от 5 до 32 знаков из латинских букв, цифр и подчёркиваний,
   начинающееся с буквы. Проверьте, что адрес https://t.me/ВАШЕ_ИМЯ ведёт к вам.
4. Сохраните файл и обновите браузер.

Появятся ссылка на студию и кнопка открытия Telegram после подготовки заявки.
Посетитель сначала копирует текст, затем сам вставляет его в чат и отправляет.
Автоматической отправки в этой версии нет. Она потребует отдельной настройки.
Никогда не размещайте токены ботов и пароли внутри script.js.

Если браузер запрещает автоматическое копирование локального файла,
сайт выделит текст. Нажмите Ctrl+C либо выберите «Копировать» вручную.
Кнопка «Скачать .txt» сохраняет заявку локально на устройство посетителя.

ПЕРЕД ПУБЛИКАЦИЕЙ

• Выберите окончательное название и добавьте реальные контакты.
• Согласуйте ваши реальные цены, состав пакетов и сроки.
• Демоконцепции не являются выполненными заказами или отдельными сайтами.
  Не выдавайте их за работы для реальных клиентов. Заменяйте их по мере
  появления своего портфолио; сейчас они подписаны как демонстрационные.
• Протестируйте кнопки, калькулятор и форму на своём компьютере и телефоне.
• Подберите домен и размещение. Все три файла должны лежать рядом.
• Когда публичный сайт будет готов, удалите из index.html строку:
  <meta name="robots" content="noindex, nofollow">
  Эта строка просит поисковики не индексировать черновик. Она не является
  паролем и не ограничивает доступ к опубликованному сайту.
• Статус «Демоверсия» в подвале меняйте после подготовки сайта к публикации.

Сайт пока не опубликован. Домен, хостинг, оплата заказов, серверная обработка
заявок, CMS и аналитика в эту локальную версию не подключены.
